# Noir Absolu

A self-contained AMOLED theme for Discord with true-black main surfaces, readable elevated panels, subtle borders, and compact scrollbars.

## Features

- True OLED black (`#000`) for the main interface
- Subtle surface hierarchy for menus, cards, inputs, and settings
- Compact, unobtrusive scrollbars
- Compatible with Discord's Dark, Darker, and Onyx appearances
- No remote CSS imports

## Installation

### BetterDiscord

1. Download `Noir-Absolu.theme.css`.
2. Open Discord settings, then BetterDiscord > Themes.
3. Open the themes folder and place the file inside it.
4. Enable **Noir Absolu**.

### Vencord

1. Download `Noir-Absolu.theme.css`.
2. Open Discord settings, then Vencord > Themes.
3. Open the themes folder and place the file inside it.
4. Load missing themes if necessary, then enable **Noir Absolu**.
