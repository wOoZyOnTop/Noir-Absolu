# Noir Absolu / Absolute Black

Collection de thèmes Discord AMOLED autonomes, avec un vrai fond noir `#000000`, des surfaces lisibles et huit couleurs disponibles.  
Self-contained AMOLED Discord theme collection with true-black `#000000` surfaces, readable panels, and eight color variants.

> Activez une seule variante à la fois. / Enable only one variant at a time.

## Fonctionnalités / Features

- Noir OLED réel / True OLED black (`#000000`)
- Titres et descriptions en français et en anglais / French and English titles and descriptions
- Liens, sélections, mentions, boutons, bordures et scrollbars accordés à chaque variante
- Compact scrollbars and readable elevated surfaces
- Compatible avec les apparences Discord Dark, Darker et Onyx
- Compatible with Vencord and BetterDiscord
- Aucun import CSS distant / No remote CSS imports

## Installation

### Vencord

1. Téléchargez la variante souhaitée. / Download the desired variant.
2. Ouvrez `Paramètres Discord > Vencord > Themes`.
3. Placez le fichier `*.theme.css` dans le dossier des thèmes.
4. Rechargez les thèmes si nécessaire, puis activez uniquement cette variante.

### BetterDiscord

1. Download the desired variant.
2. Open `Discord Settings > BetterDiscord > Themes`.
3. Place the `*.theme.css` file in the themes folder.
4. Enable only that variant.
